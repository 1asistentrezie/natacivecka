# Natáčecí den

Webová aplikace pro natáčecí den seriálu (program dne, stavy obrazů, sledování času, scénáře a složky).

- Štáb: otevře stránku a vidí aktuální natáčecí den, mění se živě.
- Editor: odkaz „Přihlásit (editor)“ dole na stránce.
- Data: Supabase (`config.js`, nastavení databáze v `supabase-setup.sql`).
